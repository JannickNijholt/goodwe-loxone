# GoodWe DT register map

Generated by `tools/build_templates.py` from `src/goodwe_modbus/registers.py`. Sources: the [goodwe](https://github.com/marcelblijleven/goodwe) library used by Home Assistant, checked against a GW10KT-DT (firmware 15.15.35).

- Addresses are Modbus PDU addresses as GoodWe numbers them; in Loxone *IO address* = address.
- All registers are holding registers (function 3). 32-bit values are high word first.
- Raw `65535` means the model doesn't have that sensor (e.g. PV3/PV4 on a 2-MPPT inverter).
- Groups: `main` = what Home Assistant shows, `extra` = diagnostics, `pv34` = MPPT 3/4, `meter` = GoodWe smart meter, `setting` = writable, `bridge` = added by the goodwe-modbus bridge.
